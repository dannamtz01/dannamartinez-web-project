# dannamartinez-web-project

## Project 2 - HTML Foundation Page

**Theme:** My webpage is a "Mexico Travel Blog". It serves as an educational and cultural exploration of Mexico's top travel destinations, highlighting historical sites like Chichen Itza, natural wonders, and providing quick travel facts. 

**What I learned:** While creating this page, I learned how to structure a document using foundational HTML4 elements and table-based layouts. I successfully adapted to the project's constraint of not using modern CSS, achieving a 1990s web aesthetic using attributes like `bgcolor` and the `<font>` tag. Additionally, I learned how to embed external media cleanly by configuring a YouTube iframe to play silently on a loop, and the importance of linking to reliable, official government data sources (like the SECTUR `.gob.mx` domain) for technical validity.

**Challenges I faced:** The primary challenge was managing the W3C Code Validation process. Because the project required a retro 1990s aesthetic without CSS, modern validators flagged several tags (like `<font>`) and attributes as obsolete or errors. I had to learn how to interpret these validation reports critically and justify the results as intentional design choices required by the project guidelines, rather than actual coding mistakes.
